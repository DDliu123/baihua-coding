# 白话编程

面向不写代码的人的术语图鉴。用你本来会说的话，搜到该用的词。

**在线地址**：https://DDliu123.github.io/baihua-coding/

---

## 它解决什么

写代码的成本被AI 压低之后，瓶颈往前挪了一格：**你知道要什么效果，但叫不出它的名字。**

举个例子。想让页面「点一下弹出一层，背景变暗，关掉才能继续」——这件事叫「弹窗（Modal）」。不知道这个词，你只能反复描述效果，AI 反复猜错；知道这个词，一句就够。

白话编程把这件事做成一张可检索的术语表：输入你真会说的话，直接拿到能用的准确表达。

## 怎么用

1. **先说人话**。用你平时会说的话描述效果或问题，比如「点了不跳页，弹出一层盖住当前页的浮层」。
2. **搜同一个词**。搜「弹窗」，直接得到技术名词、别名和使用边界。
3. **拿走能用的表达**。每条术语都有一段可复制的指令，把【】里的内容换成你的具体功能点，粘给AI 就能用。

站内另有两个入口：

- **不知道该搜什么**，从 7 个任务分组下的症状胶囊进入，比如「点不动」「本地好好的上线就坏」。
- **按侧栏筛选**，可按技术主题（前端 / 后端 / AI / 产品 / 测试 / 技术栈 / Git / 设计风格）或按分类细分收窄。

## 内容规模

| 项 | 数量 |
| --- | --- |
| 术语 | 401 |
| 任务分组 | 7 |
| 技术主题 | 8 |
| 分类细分 | 39 |
| 症状入口 | 34 |
| 附代码示例的术语 | 64 |

七个任务分组按「你此刻要做的事」组织，不按技术体系：把界面做出来 / 让它有反馈 / 装上数据 / 上线不崩 / 接入 AI / 去掉 AI 味 / 想清楚要做什么。

每条术语包含：中文名与英文名、一句话痛点、用户原话（scenes）、使用边界（pitfalls）、最小代码示例（code）、以及一段可复制给 AI 的指令（aiPrompt）。

## 技术说明

纯静态，无构建步骤、无框架依赖、无后端、无外部请求。

```
index.html            页面骨架
assets/
  app.css             设计令牌与布局
  detail.css          字体声明 + 术语详情内容区块
  app.js              交互层（原生JS）
  data/taxonomy.js    术语数据（window.BHC）
```

本地预览：

```bash
python -m http.server 8848
# 打开 http://127.0.0.1:8848
```

字体、图标均已自托管，页面不请求任何第三方资源。

## 重新构建数据

术语数据由 `~/.workbuddy/skills/baihua-coding/corpus.json` 生成。构建脚本内置一道来源断言：逐字段比对外部来源语料，若输出中检出非自撰文本即中止构建，防止混入他人内容。

```bash
python tools/build_clean.py
```

## 内容边界

这个项目**不教写代码，也不替你做技术选型**。它只负责把需求表达推进到「能被正确理解」这一步。

覆盖范围按「不写代码的人会碰到什么」来选：前端、AI 接入、产品设计较完整，偏深的后端运维较薄。
